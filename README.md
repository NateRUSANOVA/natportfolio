# natportfolio

Portfolio website of Nataliia — UX/UI designer. Built with Vite, React and TypeScript; deployed on Vercel.

The site plan lives in [`План сайту-портфоліо UX UI дизайнерки.md`](./План%20сайту-портфоліо%20UX%20UI%20дизайнерки.md).

## Development

```bash
npm install
npm run dev      # local server
npm run build    # type-check + production build
```
